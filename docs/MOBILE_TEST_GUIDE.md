# 手机通知测试指南

当前版本已经完成 PWA 和 Web Push 基础设施，但**还不能安全地让手机直接访问电脑上的 SorenOS**：Core 只在电脑本机 `http://127.0.0.1:8787` 运行，而手机安装 PWA 与 Push 需要安全的 HTTPS 页面；项目还没有局域网登录保护。请不要把 Core 改成无密码的公网或局域网服务。

电脑本机可以先验证完整流程：

1. 按项目 README 启动 Soren Core，打开 `http://127.0.0.1:8787`，右上角应显示 `Core Online`。
2. 浏览器支持安装时，从地址栏的安装入口把 SorenOS 安装为独立应用。
3. 打开 `Settings → 通知`，打开“系统通知”并保存。
4. 点击“连接此设备”。只有这一步才会出现浏览器权限框；选择允许。
5. 点击“发送测试通知”，系统应显示发送者为 `Soren` 的通知。
6. 在 CyberDaddy 中启用总开关和对应领域，创建一个目标时间为当前时间 5 分钟后的测试承诺，并保持 Core 运行。
7. 到期且 CyberDaddy 判断需要跟进时，消息会先写入 Soren Chat，再投递系统通知；设备锁屏时也应由操作系统展示。
8. 点击通知应打开已有 SorenOS 窗口或启动 PWA，并进入保存该主动消息的会话。
9. Home Note 与朋友圈只更新应用内状态，因此不会弹系统通知，这是既定隐私和打扰规则。
10. 电脑关机后 Core、CyberDaddy scheduler 都不会运行，也不会产生新的 Chat 或 Push。24 小时在线能力需要后续选择常驻电脑、家庭设备或私人服务器。

实体手机测试需先完成“受信任 HTTPS + 设备认证 + 安全的 Core 访问”小阶段；本轮没有用关闭 TLS、无鉴权监听或硬编码公网地址绕过这一条件。
